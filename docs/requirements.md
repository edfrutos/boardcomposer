# Requisitos iniciales

## Funcionales

RF-001 Introducción manual de tablas.
RF-002 Importación desde CSV/Excel.
RF-003 Definición de restricciones.
RF-004 Generación de múltiples soluciones.
RF-005 Puntuación configurable.
RF-006 Visualización gráfica.
RF-007 Inventario de uno o varios tableros con cantidad y espesor.
RF-008 Asignación y validación de cada pieza sobre un panel físico.
RF-009 Persistencia de la asignación multipanel.
RF-010 Exportación visual multipanel.

## No funcionales

- Arquitectura modular.
- Rendimiento escalable.
- Código testeable.
- Documentación mantenida desde el inicio.
- Compatibilidad hacia atrás de proyectos persistidos.
- Resultados reproducibles y explicables por panel.
