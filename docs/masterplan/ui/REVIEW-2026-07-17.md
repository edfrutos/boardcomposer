# Revisión UI — `docs/masterplan/ui/` vs Studio real

**Fecha:** 2026-07-17  
**Alcance:** contraste de SCR-001…007 y FLW-002 con el Studio actual en `main`.

## Resumen

| Pantalla / flujo | Estado vs Studio | Notas |
|---|---|---|
| SCR-001 Inicio | Parcial | Studio arranca en Workspace vacío/demo; no hay splash/home dedicado. |
| SCR-002 Workspace | Alineado | Paneles lado a lado, arrastre, reasignación entre paneles, zoom/cámara. |
| SCR-003 Comparador | Parcial → usable | Tabla con métricas, resaltado por métrica, ordenar/filtrar. Faltan miniaturas sincronizadas y panel de diferencias visual. |
| SCR-004 Inspector | Alineado | Pieza (dims, posición, tablero/instancia, material) y resumen de layout/diagnóstico. |
| SCR-005 Proyecto | Alineado | Nuevo/abrir/guardar, recientes, tableros/piezas, import CSV tableros y piezas. |
| SCR-006 Preferencias | Pendiente | No hay pantalla de preferencias ni pesos de scoring editables. |
| SCR-007 Exportación | Parcial → usable | SVG, DXF y PDF de la solución seleccionada. Faltan CSV/JSON de export y opciones avanzadas. |
| FLW-002 Importar CSV | Parcial → usable | Tableros y piezas con vista previa. Excel (.xlsx) pendiente. |

## Brechas prioritarias (siguientes)

1. Preferencias (SCR-006): estrategia y pesos de scoring.
2. Comparador: miniaturas / vista gráfica lado a lado (SCR-003 completo).
3. Excel en importación CSV (FLW-002).
4. Pantalla de inicio opcional o flujo “bienvenida” (SCR-001), si se confirma valor de producto.

## Conclusión

El Studio cubre el núcleo operativo del UAT multipanel (Workspace, Inspector,
Proyecto, export básico, import CSV). Los documentos UI siguen siendo la
visión objetivo; esta revisión deja marcado qué está hecho y qué queda
como evolución, sin reescribir todavía cada SCR.
